# Security policy

## Supported releases

`v0.1.0` is an unsafe preview and is not supported for production use. Only the
latest package version published to npm by the protected release workflow is
supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue with exploit details, credentials, financial data, or tenant
identifiers. Include the affected version, impact, reproduction steps, and the
smallest sanitized evidence that demonstrates the issue.

The maintainers will acknowledge a complete report, coordinate remediation and
disclosure privately, and publish an advisory when users need to take action.
